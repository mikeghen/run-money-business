# Community research: where Run Money can post or partner

_Issue #3 · Plan, Oct 16, 2026 · Sharon. Updated Nov 1: runs at crypto conferences, two more run clubs, new dates. Public sources only, re-checked Oct 15 and Nov 1. Living list; will update as we reach out._

## The short version

- **Best audience now: crypto people who already run.** Regular runners later, once getting the ETH + USDC is simpler for people new to crypto.
- **Several of the best-fit crypto runners we found post on Farcaster.** Small crowd, but 2–3 real relationships there are worth it. Join now. X stays the main public channel.
- **Crypto people run together at conferences.** Morning fun runs at events like Devcon, not weekly crypto run clubs.
- **Nobody else does what we do.** Other run-to-earn apps pay in tokens that collapse. Real interest, no token.

~120 communities, creators and events looked at, each re-checked as still active. 52 made the cut: [partners.csv](partners.csv) (name, link, what it is, why it fits, priority, contact). Highlights below.

The one healthy runner channel on Farcaster: ~30.7k followers, real runners posting Strava runs. Hosts: @alor, @camilags. Join now, take part, then post an honest how-it-works and invite runners to Run Money.

## Later

- **Strava:** big brand clubs are closed and paid challenges are expensive. Free option: a Strava Group Challenge (up to 199 people).
- **Move-to-earn communities** (STEPN, Sweat): paid partnerships only, other chains.
- **Telegram groups:** hard to find and size without joining. In the list now: Nouns Running Club. More once we join a few.
- **UK-based creators:** UK rules restrict promoting crypto. Skip for now.
- **Runner newsletters, YouTube/TikTok running creators:** once getting started is simpler for people new to crypto.
- **Local Philly:** a quick Run Money mention at CryptoMondays Philly if Mike still co-hosts it (next: Oct 19, Nov 16). Philly run clubs later, for the same reason.
